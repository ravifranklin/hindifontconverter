Preeti data is calibrated from 135 independent input/output observations of the public reference tool, recorded in docs/preeti-observations.json. Marker handling (pre-base i and reph), longest-match lookup and reverse ordering are original code. Standard keyboard readings were researched in public documentation including https://github.com/dpr4dhan/preeti-to-unicode, but no upstream implementation or post-processing rules are vendored. That repository cites noncommercial Shuvayatra and GPL-3.0 npttf2utf sources, so its implementation was deliberately excluded. Six extended symbols that the reference preserves unchanged (including ÷) are also preserved; this is documented as a limitation rather than guessed.
